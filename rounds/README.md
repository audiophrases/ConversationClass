# Rounds folder

Lessons in this folder show up in Conversation Class on every device, under **☁️ GitHub rounds folder** in the lesson menu. No login or token is needed to use them.

To add or update a lesson:

1. In the app, pick the lesson and press **⬇️ Export**. You get a `.json` file.
2. Upload it here: **Add file → Upload files** (signed in to GitHub). Uploading a file with the same name replaces the old version.
3. In the app, press **↻ Refresh** next to "GitHub rounds folder", or just reload the page.

Only `.json` files are read. This repository is public, so anything here, including photos uploaded in the editor, is public too.
